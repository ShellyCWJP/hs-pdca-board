課題研究（情報）　サンプルアプリの記録 ②

PDCA Board のしくみ

アプリはどこで動いて、データはどこにあるのか。
使った道具と、それぞれの役割、選んだ理由。

全体図

3 つの場所と、2 本の道

使うときの道作るときの道

場所 1：ブラウザ

見える部分を作る道具

  • React画面を部品の組み合わせで作る
  • TanStack RouterURL と画面を対応させる（/student、/teacher …）
  • shadcn/uiボタン・表・入力欄などの既製部品
  • Tailwind CSS色や余白を、短い名前で指定する

場所 2：Cloudflare Workers

裏で働く部分

  • Cloudflare Workersアプリのプログラムを、世界中の Cloudflare の拠点で動かす
  • TanStack Start「保存」「ログイン」などの処理を、画面と同じコードの中に書ける

自分でサーバー機を用意しない。パソコンを閉じてもアプリは動き続ける。

場所 3：Cloudflare D1

記録をしまう場所

  • Cloudflare D1表の形でデータを保存するデータベース（中身は SQLite）
  • drizzle表の形をプログラムで定義し、読み書きを書きやすくする

「並べる・数える・探す」が得意。達成率の平均もここで計算できる。

安全のしくみ

パスワードは
そのまま保存しない

  • ハッシュ化元に戻せない形に変換してから保存。先生でも中身は見えない
  • Cookie セッションログイン後は「合言葉」をブラウザが持ち、毎回の通信に添える

既製の認証サービスは使わず、自分で書いた。しくみを見せるため。

1 回の操作が通る道

「保存」を押すと、何が起きる？

作るときの道具

手元のパソコンで使ったもの

  • TypeScript型でミスを実行前に見つける
  • Vite書いたそばから画面に反映する開発サーバー
  • pnpmライブラリの取り寄せと、コマンドの実行
  • wranglerCloudflare に置く・D1 を操作する
  • GitHubコードの履歴と置き場
  • Claude Code要件の整理からコードまで、AI と相談しながら進めた

選んだ理由 1

なぜ Cloudflare？

サーバー機を持たなくていいプログラムを置くだけ。OS の更新や電源の心配がない
無料枠で足りる1 クラス分のアクセスなら、費用はかからない
アプリと DB が同じ場所Workers と D1 がセットで使えて、設定が少ない
公開が 1 コマンドwrangler deploy で URL が出る

選んだ理由 2

なぜ TanStack Start？

画面と裏の処理を 1 つのコードで「保存する関数」を書けば、ブラウザからそのまま呼べる
React が使える参考資料が多く、部品（shadcn/ui）もそのまま使える
Cloudflare Workers で動く公式の設定がある

同じ役割の道具に Next.js もある。今回は「Workers との相性」と「しくみの見えやすさ」で選んだ。

選んだ理由 3

なぜ shadcn/ui？

部品のコードが手元に来るダウンロードして使うのではなく、コピーして自分のものにする。中を読める・直せる
必要な部品だけボタン、表、入力欄、ダイアログ、グラフ。11 個だけ入れた
Tailwind と相性がいい色や余白をその場で調整できる

公開までの流れ

手元 → GitHub → Cloudflare

まとめ

役割ごとに道具は 1 つ。少なく選ぶ

画面・裏の処理・データ・置き場所。
それぞれに 1 つずつ。増やすのは、困ってからでいい。
